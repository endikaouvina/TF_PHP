# SITIO WEB

Se trata de un sitio web en el que cualquier visitante se puede registrar como usuario y solicitar, editar y eliminar citas; y los administradores podrán crear, editar y eliminar usuarios, citas de usuarios y noticias, además de ver sus correspondientes listados.

## DATOS DEMO

En el archivo `sql/tf_php_data_demo.sql`, se incluyen instrucciones con datos demo para poder acceder y explorar todo el sitio web. Los datos de acceso a los diferentes administradores y usuarios son los siguientes:

- Usuario: `admin1`, contraseña: `admin1` (rol: `admin`).
- Usuario: `admin2`, contraseña: `admin2` (rol: `admin`).
- Usuario: `admin3`, contraseña: `admin3` (rol: `admin`).
- Usuario: `user1`, contraseña: `user1` (rol: `user`).
- Usuario: `user2`, contraseña: `user2` (rol: `user`).
- Usuario: `user3`, contraseña: `user3` (rol: `user`).
